# jointoml

Join and reshape toml text streams with deterministic transforms.

**Site:** https://theworker02.github.io/jointoml/

## Install / run

```bash
git clone https://github.com/theworker02/jointoml.git
cd jointoml
node src/cli.js
node --test
```
