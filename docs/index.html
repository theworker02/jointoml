Overview

Join and reshape toml text streams with deterministic transforms. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/jointoml.git
cd jointoml
node src/cli.js --help
node --test
